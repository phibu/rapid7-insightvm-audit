## Task 1 (M1): `assumed_*_minutes` ≤0 guard

### Context

Backlog note from 0.6.5 code review: `int(rule_config.get("assumed_*_minutes", ...))` casts in `overlapping_scan_windows.py` and `scan_report_schedule_overlap.py` don't guard against zero or negative values. A zero collapses the overlap window to a point in time (silent suppression of findings); negative produces broken `timedelta`. Non-numeric strings raise `ValueError` which surfaces as a `status="error"` rule -- that behavior is the project pattern for bad config and should be **preserved**.

### What to implement

In both rule files, wrap each `int(rule_config.get(...))` call with `max(1, ...)`:

```python
# Before
duration_minutes = int(rule_config.get("assumed_scan_duration_minutes", 60))

# After
duration_minutes = max(1, int(rule_config.get("assumed_scan_duration_minutes", 60)))
```

**Files:**
- `src/rapid7_healthcheck/audit/rules/overlapping_scan_windows.py` -- find the `assumed_scan_duration_minutes` read (search for it)
- `src/rapid7_healthcheck/audit/rules/scan_report_schedule_overlap.py` -- find `assumed_report_duration_minutes` AND `assumed_scan_duration_minutes` reads

The `int()` call still raises `ValueError` on non-numeric strings -- caller's `safe_run` wrapper converts that to a `status="error"` rule. Don't add a try/except -- that would change the bad-config-is-error semantic.

### TDD

For each rule, add tests in the existing test file (find via `tests/audit/rules/test_overlapping_scan_windows.py` etc):

**Step 2: the rule.**

In `src/rapid7_healthcheck/checks/asset_coverage.py`, find the existing rule classes (e.g. `MissingOsRule`'s style at `checks/data_quality.py:81-117` is the canonical template). Add a new rule class:

```python
class GhostAssetsRule:
    RULE_ID = "op.asset_coverage.ghost_assets"
    RULE_NAME = "Ghost assets (no OS AND no hostname)"
    DESCRIPTION = (
        "Assets the console knows about but cannot identify -- neither an OS "
        "fingerprint nor a hostname. Typically the result of stale agent "
        "registrations, network-only scans of unreachable hosts, or import "
        "errors. Stricter than the data-quality 'missing OS' rule, which "
        "flags on either gap alone."
    )
    DEFAULT_SEVERITY = "fail"
    SOURCES = (_SRC_ASSET_SEARCH,)  # use whatever constant the file already defines

    def run(self, client, t) -> RuleResult:
        if not t.flag_ghost_assets:
            return skipped_rule(
                rule_id=self.RULE_ID,
                rule_name=self.RULE_NAME,
                description=self.DESCRIPTION,
                sources=self.SOURCES,
            )

        rule_start = time.monotonic()
        # Server-side: assets with no OS fingerprint (small candidate set).
        body = client.post_one(
            "/api/3/assets/search",
            json_body={
                "filters": [{"field": "operating-system", "operator": "is-empty"}],
                "match": "all",
            },
            params={"size": _PER_ITEM_FINDING_CAP * 2},
        )
        candidates = body.get("resources", [])

        # Client-side: narrow to those also missing hostName.
        ghosts = [
            a for a in candidates
            if not (a.get("hostName") or "").strip()
        ]

        findings: list[Finding] = []
        emitted = 0
        for ghost in ghosts:
            if emitted >= _PER_ITEM_FINDING_CAP:
                break
            findings.append(Finding(
                severity="fail",
                message=f"Asset id={ghost.get('id')} has no OS and no hostname (ghost record)",
                details={
                    "id": ghost.get("id"),
                    "ip": ghost.get("ip"),
                    "mac": ghost.get("mac"),
                },
            ))
            emitted += 1

        if len(ghosts) > emitted:
            findings.append(Finding(
                severity="warn",
                message=(
                    f"{len(ghosts) - emitted} additional ghost assets omitted "
                    f"from findings (capped at {_PER_ITEM_FINDING_CAP})"
                ),
            ))

        return make_rule_result(
            rule_id=self.RULE_ID,
            rule_name=self.RULE_NAME,
            description=self.DESCRIPTION,
            findings=findings,
            sources=self.SOURCES,
            summary={
                "ghost_count": len(ghosts),
                "candidates_examined": len(candidates),
            },
            default_severity=self.DEFAULT_SEVERITY,
            duration_ms=int((time.monotonic() - rule_start) * 1000),
        )
```
