### 4b. Update `index()` to walk top-level findings

- [ ] **Step 4.3: Add the second loop to `index()`**

In `src/rapid7_healthcheck/report.py`, find the `_compute_delta` function and its inner `index()` helper. The current implementation looks like:

```python
def index(state: dict) -> dict[str, dict]:
    out: dict[str, dict] = {}
    for r in state.get("results", []):
        for rr in r.get("rule_results", []) or []:
            rule_id = rr.get("rule_id")
```

Replace the body with:

```python
def index(state: dict) -> dict[str, dict]:
    out: dict[str, dict] = {}
    for r in state.get("results", []):
        check_name = r.get("name")
        # Audit-rule findings.
        for rr in r.get("rule_results", []) or []:
            rule_id = rr.get("rule_id")
            for f in rr.get("findings", []):
                sig = f.get("signature")
                if sig:
                    out[sig] = {**f, "rule_id": rule_id}
        # Operational-check top-level findings (use check_name as namespace).
        for f in r.get("findings", []) or []:
            sig = f.get("signature")
            if sig:
                out[sig] = {**f, "rule_id": check_name}
    return out
```

The new second loop walks `r.get("findings", []) or []` (handling both missing key and explicit None), uses `check_name` as the `rule_id` for projection consistency, and adds to the same `out` dict. Signatures are unique across both audit-rule and operational-check sources because the projection (Task 4 in 0.1.9's plan) already namespaces top-level finding ids as `f"{check_name}#{idx}"`.

```markdown
- User-audit rule `sources` URLs standardized on `docs.rapid7.com/insightvm/`,
  with deep-section anchors where clear. Verified all URLs return HTTP 200 at
  release time.

### Added
- `rules_error` metric bucket. The metric grid now shows error-status rules in
  their own tile, and `rules_total` matches the sum of severity buckets again.
- `_compute_delta` now includes operational-check top-level findings (scan
  engines, scan activity, asset coverage, data quality). Previously deltas
  covered audit-rule findings only.
- Print stylesheet now force-expands `<details>` cards on paper, so printed
  reports show finding details, sources, and sample notes inline.

### Internal
- `report.py` import aliases (`_re`, `_time`) replaced with plain `re` / `time`.
- `CLAUDE.md` documents the embedded state-blob convention introduced in 0.1.9.
```
