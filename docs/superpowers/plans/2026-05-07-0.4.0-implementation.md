```python
def test_setup_logging_calls_basicconfig_before_file_open_warning(tmp_path, monkeypatch):
    """When log_file open fails, basicConfig must run BEFORE the warning is
    emitted, so the warning travels through the new handlers (not the old
    ones from the previous _setup_logging call that are about to be torn down).

    Verified by mocking both logging.basicConfig and the module-level warning
    call site, then asserting the recorded call order.
    """
    import logging
    from rapid7_healthcheck import __main__ as main_mod

    calls: list[str] = []

    real_basic_config = logging.basicConfig

    def fake_basic_config(*args, **kwargs):
        calls.append("basicConfig")
        return real_basic_config(*args, **kwargs)

    monkeypatch.setattr(logging, "basicConfig", fake_basic_config)

    # Spy on the warning method of the module-level logger that _setup_logging
    # uses (logging.getLogger(__name__) inside the function resolves to the
    # __main__'s module logger).
    module_logger = logging.getLogger("rapid7_healthcheck.__main__")
    real_warning = module_logger.warning

    def fake_warning(msg, *args, **kwargs):
        calls.append("warning")
        return real_warning(msg, *args, **kwargs)

    monkeypatch.setattr(module_logger, "warning", fake_warning)

    # Force file-open failure: log_file path is inside a parent that exists
    # but is read-only. Simplest cross-platform trigger: a path inside a
    # file (not a directory). On every OS, mkdir(parents=True) on a path
    # whose parent is a regular file raises NotADirectoryError (or OSError).
    parent_file = tmp_path / "iam_a_file"
    parent_file.write_text("x")
    bad_log_path = str(parent_file / "subdir" / "out.log")

    main_mod._setup_logging(verbose=False, log_file=bad_log_path, log_format="plain")

    # Both should have been called.
    assert "basicConfig" in calls, f"basicConfig was not called: {calls}"
    assert "warning" in calls, f"warning was not called: {calls}"
    # And basicConfig must come BEFORE warning.
    assert calls.index("basicConfig") < calls.index("warning"), (
        f"basicConfig must precede warning in _setup_logging; got order {calls}"
    )
```

In `src/rapid7_healthcheck/__main__.py:100-107`, the current code reads:

```python
    logging.basicConfig(
```

Swap the two blocks so `basicConfig` runs first:

```python
    logging.basicConfig(
        level=level,
        format="%(asctime)s %(levelname)s %(name)s: %(message)s",

        force=True,
    )
```

The semantics: with `force=True`, `basicConfig` tears down any existing root handlers and installs `handlers`. The subsequent `logger.warning(...)` call propagates to the new root handlers. When `file_open_error` is `None` (the common case), the conditional doesn't fire and behavior is identical to today.

- [ ] **Step 3: Add the autouse fixture at the top of `test_logging_setup.py`**

In `tests/test_logging_setup.py`, after the existing imports at the top of the file, insert:

```python
import logging as _logging_for_fixture
import pytest as _pytest_for_fixture
from rapid7_healthcheck._log import FlushingFileHandler as _FlushingFileHandler_for_fixture


@_pytest_for_fixture.fixture(autouse=True)
def _strip_flushing_file_handlers_after_test():
    """Strip any FlushingFileHandler instances from the root logger after each
    test in this file.

    _setup_logging uses basicConfig(force=True), which installs handlers on the
    root logger. Without this fixture, a FlushingFileHandler installed by one
    test stays on root and may fire on subsequent tests, writing through a file
    descriptor whose underlying tmp_path has already been torn down. No flake
    has been observed in practice (deterministic ordering, no xdist), but this
    is the surgical fix for the leak. Conservative isinstance() filter only —
    leaves caplog's own root-logger handler and any default StreamHandler
    untouched.
    """
    try:
        yield
    finally:
        root = _logging_for_fixture.getLogger()
        for h in list(root.handlers):
            if isinstance(h, _FlushingFileHandler_for_fixture):
                root.removeHandler(h)
                h.close()
```

(The `_for_fixture` suffixes on the imports avoid colliding with any existing top-of-file imports of `logging`/`pytest`/`FlushingFileHandler` in the same test file. If those exact names happen to be unused elsewhere in the file, you may use the unsuffixed names — read the existing imports first and match. Either choice is correct; the `_for_fixture` versions are guaranteed safe.)
